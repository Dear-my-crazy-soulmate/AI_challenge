## 2026-10-28 모델 비교 (`2026-10-28-model-comparison.json`)

- 목적: 조합 설명에 쓸 ChatKHU 모델 고르기, 그리고 "그냥 ChatKHU에 물어보면 되지 않나?"에 답하기
- 방법: 조합 2개(컴퓨터공학과+소프트웨어융합학과, 스마트팜과학과+원예생명공학과 다전공) × 모델 3개(solar-pro4, claude-haiku-5-5, gemini-3.8-flash) × 질문 2가지
  - 그냥 질문: 자료 없이 학점·필수 과목·강점을 물음
  - 근거 질문: 앱의 계산 결과와 책 원문을 주고 정해진 JSON으로 쓰게 함, 코드로 검사
- 비용: 12회 호출, 44 크레딧

| | 실제 (책·계산기) | solar-pro4 | gemini-3.8-flash | claude-haiku-5-5 |
|---|---|---|---|---|
| 그냥 질문: 컴공+소융 | 51+51=102, 최소 84 | "다전공 36~45학점" | 범위로만 답함 | 모른다고 답함 |
| 그냥 질문: 스마트팜+원예 | 51+45=96, 최소 90 | "다전공 36~45학점" | "각 39~42, 합 80~84" | 모른다고 답함 |
| 근거 질문 검사 | – | 2개 모두 문제 1건 | 출력 잘림 | **2개 모두 통과** |

결론: 학점은 코드가 계산하고, ChatKHU에는 학점을 맡기지 않는다. 설명은 claude-haiku-5-5.
